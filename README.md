# 📋 TaskVerse

A simple and responsive task-management web app created while learning HTML, CSS and JavaScript.

## ✨ Features

* ➕ Add tasks
* ⌨️ Add tasks using the Enter key
* ☑️ Mark tasks as completed
* 📊 Track daily progress
* 🗑️ Delete tasks
* ☀️🌙 Light and dark themes
* 📱 Responsive design for laptop, tablet and mobile

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🎯 What I Practiced

* DOM manipulation
* Event listeners
* Dynamic task creation
* Checkbox events
* Progress calculation
* Theme switching
* Responsive CSS
